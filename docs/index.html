FROM INSPIRATION TO CREATION

看到喜欢的，就去试试。

01打开案例，选择智能体

在详情的「安装并使用」里选择 Codex、Cursor、Claude Code 或其他智能体。

02把安装请求带过去

Codex、Cursor 支持唤起应用并预填请求；在应用中发送后才会执行。其他智能体可直接复制请求并粘贴。

03提供素材，开始创作

智能体会定位对应技能、检查依赖，并告诉你需要提供什么。已有 Skill 可直接使用案例里的提示词。

提示词案例无需安装；工具和工作流按原项目配置。网页无法读取你的本机安装状态，完成后可在智能体里确认。
