# Inspiration Studio — Demo 02

独立交互版本，保留正式版、Discovery 2 快照和 Demo 01。

作品展台：三个精选项目淡入切换、键盘方向键、触屏滑动、轻微滚动视差、指针跟随。
索引：八个真实项目，分类筛选，悬停与焦点预览；手机展示缩略图索引。
作品面板：原生对话框、展开/关闭动画、完整作品图、作者、准备材料、依赖、核验与授权信息、上下作品切换。
搜索：Ctrl/Cmd K 打开，关键词过滤，可直接进入作品面板。

尊重减少动态效果偏好，不自动轮播，不修改浏览器收藏数据。
样图是现有公共收录中的作者示例，并非本站复现。优先使用本地缩略图，原图加载完成后逐步替换；原图失败时保留缩略图。
