## 体验

- 按生图、剪辑、场景、资源类型和整理状态筛选。
- 统一搜索；卡片与列表切换；图片放大与原始资料查看。
- 一键收藏、最近浏览、自动保存笔记和手动收录链接。
- 跨生图和剪辑组合创作清单，调整顺序，复制完整创作简报。
- JSON 备份导入导出，兼容旧生图图录与剪辑收藏。
- 手机导航抽屉、键盘搜索、原生对话框和减少动态效果支持。
- 案例详情中的「安装并使用」：选择 Codex / Cursor 可打开应用并预填安装请求；Claude Code 等智能体可复制请求。用户在应用中发送后才会执行。
- 已定位的 Skill 使用精确入口；多技能仓库会先定位对应技能。提示词案例和普通工作流不会生成 Skill 安装命令。
- 可选终端安装方式使用 `npx skills add`，按所选智能体生成命令；网站不读取本机安装状态，也不把跳转成功当作安装完成。

Codex 启动能力见 [官方 Commands 文档](https://learn.chatgpt.com/docs/app/commands)，Cursor 见 [官方 Deeplinks 文档](https://prod.cursor.com/docs/reference/deeplinks)，通用安装命令见 [Vercel Skills](https://github.com/vercel-labs/skills/blob/main/docs/commands.md)。

## 运行与发布

`docs/` 是无需构建的完整网站。可用任意静态 HTTP 服务预览。

GitHub Actions 自动将 `docs/` 发布到 GitHub Pages；提交前端修改后也会自动重新部署。

## 每日自动收录

每天北京时间 **09:17**（UTC 01:17），GitHub 云端会分别搜索生图与剪辑方向的公开项目：轮换关键词与索引 → 读取匹配的 Skill / 项目说明 → 提取来源、许可与公开样图 → 去重保留 → 更新网站。计划运行可能受 GitHub 调度影响而延迟。

- 两个方向分别记录新增、检查数量、队列与失败来源；一个来源失败会保留已有资料。
- 新发现进入「自动发现」候选区，可按生图 / 剪辑切换；人工精选库保留。
- 普通 Python 脚本，不调用 AI，不安装或运行收录到的项目代码，无需保持个人电脑开机。
- 页面每 5 分钟检查数据更新；「收录动态」可查看两个方向的最近结果与云端运行记录。
- 从 GitHub Actions 手动运行 `Daily collection and Pages` 也可立即收录；关闭 `collect` 输入则只部署网站。
- [采集配置](collector/sources.json)维护关键词与请求预算；修改每日时间时，同步调整工作流的 UTC cron 与配置中的北京时间。[运行记录](https://github.com/fledgling-david/inspiration-studio/actions/workflows/daily-collect.yml)可查看每次执行。

小红书、X 等平台目前支持手动收录链接，尚未接通自动采集。

收藏、个人笔记和创作清单保存在浏览器 localStorage。不同网址、浏览器和设备之间，使用「数据与备份」迁移。

## 来源与使用范围

这是创意资源与研究图录，网站本身不执行生成图片或剪辑视频任务。每项资料保留原项目地址、示例图署名、运行条件、核验范围与许可信息。自动发现候选尚未逐项实测。

示例图片及第三方项目归原作者，遵循各自许可；仓库代码的公开不改变第三方内容的使用范围。完整来源见 [catalogue.json](docs/data/catalogue.json) 与网站详情页。

「全部灵感」及生图、视频分类包含已整理案例、每日自动发现和当前浏览器的个人收录，数量按实际内容统计。自动发现作为按最近收录排列的快捷入口；卡片与详情以「已整理 / 待核验 / 手动收录」标注来源状态，可在筛选中选择。个人整理状态不会改变公开核验标签。
